## 👨‍💻 A little about me

I'm a software engineer who enjoys going all the way from an idea to a production-ready product.

I work across **frontend, backend, databases, AI, automation, cloud and DevOps**, which means I don't like thinking of software as isolated pieces. I like understanding how the whole system fits together — how a UI talks to an API, how services communicate, how data flows, how AI fits into the workflow, and how everything gets deployed and maintained in production.

Right now, I'm particularly interested in **AI automation and agentic systems** — building software where models don't just generate responses, but actually reason, use tools, coordinate tasks and become part of useful workflows.

### 🔭 What I'm working on

* Building **full-stack web & mobile applications** with production deployment in mind.
* Exploring **agentic AI, AI automation and multi-step intelligent workflows**.
* Working with **n8n, LangGraph, PyTorch, scikit-learn and XGBoost**.
* Going deeper into **cloud infrastructure, CI/CD and production DevOps**.
* Learning **Go, Rust and Google Cloud Platform**.
* Constantly experimenting with new ideas and turning them into working software.

### 💬 Ask me about

**JavaScript, TypeScript, Python, Dart, React, Flutter, Node.js, FastAPI, MongoDB, PostgreSQL, AI/ML, AI automation, agentic development, DevOps, CI/CD and production deployment.**
